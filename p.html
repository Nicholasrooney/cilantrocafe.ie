Cilantro setup

Setup is locked

To unlock it, create an empty file on the server at:

public_html/includes/secrets/SETUP-ALLOWED

In hPanel, that is File Manager → open includes/secrets → New File → name it exactly SETUP-ALLOWED with no extension.

This is here so that only somebody with access to the server can point this site at a database — knowing the web address is not enough. The file is deleted automatically when setup finishes.
